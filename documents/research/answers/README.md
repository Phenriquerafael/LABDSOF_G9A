# Registo das entrevistas simuladas — DISC-01-02

## Método e proveniência

Oito documentos com perfis fictícios, datados de **2026-10-21**, preservados no commit [22dedb5](https://github.com/Phenriquerafael/LABDSOF_G9A/commit/22dedb5246ddec97d0e731a0582ad8ee9a6d099f). A data é de criação, não de sessão. A ferramenta/modelo e o processo original de geração não foram fornecidos; a autoria do commit não identifica o autor de cada resposta.
